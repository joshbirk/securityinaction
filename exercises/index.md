Hands-on exercises for hardening your Salesforce org. Work through these in order — each builds on what came before.

1. **[Take Action with Health Check](01-health-check.html)** — Get oriented with the Health Check tool and your current security score.
2. **[Update Session Security](02-session-security.html)** — Enable MFA, configure login IP ranges, and lock down session policies.
3. **[Dive into User Security](03-user-security.html)** — Use User Access Summaries and reports to find and fix over-privileged users.
4. **[Configure Health Check](04-configure-health-check.html)** — Customize password policies, set up notifications, and create a custom baseline.
5. **[Fix Remaining Risks (Optional)](05-fix-remaining-risks.html)** — Bulk-resolve the remaining settings against your baseline.
6. **[Secure Your Data with Shield](06-shield.html)** — Use Data Detect to find PII hiding in plain text fields.
