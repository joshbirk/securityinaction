# Exercises

Hands-on exercises for hardening your Salesforce org. Work through these in order — each builds on what came before.

1. **[Take Action with Health Check]({% link exercises/01-health-check.md %})** — Get oriented with the Health Check tool and your current security score.
2. **[Update Session Security]({% link exercises/02-session-security.md %})** — Enable MFA, configure login IP ranges, and lock down session policies.
3. **[Dive into User Security]({% link exercises/03-user-security.md %})** — Use User Access Summaries and reports to find and fix over-privileged users.
4. **[Configure Health Check]({% link exercises/04-configure-health-check.md %})** — Customize password policies, set up notifications, and create a custom baseline.
5. **[Fix Remaining Risks (Optional)]({% link exercises/05-fix-remaining-risks.md %})** — Bulk-resolve the remaining settings against your baseline.
6. **[Secure Your Data with Shield]({% link exercises/06-shield.md %})** — Use Data Detect to find PII hiding in plain text fields.
